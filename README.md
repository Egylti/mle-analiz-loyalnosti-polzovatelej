# Анализ лояльности пользователей Яндекс Афиши

Проект загружает заказы и курсы валют из CSV-файлов, очищает данные и считает долю повторных покупок.

## Подготовка

Нужен Python 3.12 или новее.

Установите библиотеки:

```bash
python -m pip install -r requirements.txt
Положите в папку data/ два файла:
- orders.csv — заказы, выгруженные из базы;
- final_tickets_tenge_df.csv — курсы тенге.
Запуск
В корневой папке проекта выполните:
python main.py
Результаты
После обработки осталось 290 569 заказов и 21 933 пользователя. Повторные покупки совершили 61,8% пользователей.

Доля повторных покупок среди пользователей с первым заказом на концерт составила 62,4%, на спортивное мероприятие — 56,2%. Разница заметна и подтверждается проверкой гипотезы.

Доля повторных покупок различается и между регионами.
Рекомендации
Стоит изучить, почему после первого спортивного заказа пользователи возвращаются реже, и проверить способы заинтересовать их новыми мероприятиями. Для регионов с низкой долей повторных покупок полезно отдельно проверить предложения и рекламные кампании
