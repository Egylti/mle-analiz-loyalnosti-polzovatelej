# Анализ лояльности пользователей Яндекс Афиши

Приложение очищает заказы, переводит выручку в рубли, строит профили пользователей и анализирует повторные покупки.

## Подготовка данных

Создайте папку `data/` и положите в неё два файла:

- `orders.csv` — результат SQL-запроса из первой части проекта. Сохраните выгрузку из JupyterHub под этим именем.
- `final_tickets_tenge_df.csv` — файл курсов валют. [Скачать файл курсов](https://code.s3.yandex.net/datasets/final_tickets_tenge_df.csv).

## Установка и запуск

Нужен Python 3.12 или новее. В Git Bash из корневой папки проекта выполните:

```bash
py -3.12 -m venv .venv
source .venv/Scripts/activate
python -m pip install -r requirements.txt
python main.py
Результаты
После очистки заказов осталось 281 840 строк. Затем исключены 217 профилей с числом заказов выше p99. Итоговая выборка: 137 568 заказов и 21 483 пользователя. Повторные покупки совершили 61,3% пользователей.

Удалены 42 совпадающих заказа, 381 заказ с отрицательной выручкой, 5 523 заказа с нулевой выручкой и 2 825 заказов выше p99 по выручке.

После первого спортивного заказа доля повторных покупок составила 54,9%, после концерта — 61,8%. Разница статистически значима (p-value = 0,0002).

В топ-10 регионов доля повторных покупок составила 62,5%, в остальных регионах — 58,3%. Доли различаются (p-value < 0,001).

По φK сильнее всего с числом заказов связаны средний интервал между заказами (0,296) и средняя выручка (0,226). Связь с регионом слабее (0,124).
Рекомендации
Провести тест кампании для пользователей, начавших со спортивных мероприятий: они возвращаются реже, чем покупатели концертов. Отдельно проверить предложения для регионов с низкой долей повторных покупок. Результаты тестов сравнивать с общей долей возврата.
